# GameSphere

Proyect to learn how to create an app for tracking your games, using Next.js + Prisma + PostgereSQL + React
## Development notes
* Run Next.js
``` 
npm run dev
```

* Run PostgreSQL

Start
```
C:\PostgreSQL\pgsql\bin\pg_ctl.exe -D C:\PostgreSQL\data -l C:\PostgreSQL\postgres.log start
```

Execute
```
C:\PostgreSQL\pgsql\bin\psql.exe -U postgres -d gamesphere
```
